# PeXClicker (Rust + Tauri)

## Özellikler

- Hız: 1–1000 tık/saniye (adım düğmeleri + kaydırıcı)
- Sol / sağ / orta tık
- İmleç konumu veya sabit nokta (F7 ile konum yakalama)
- Rastgele aralık (jitter)
- Tıklama sınırı: sınırsız / 100 / 500 / 1000
- Başlat/durdur kısayolu (F1–F12 arasında değiştirilebilir, varsayılan F6)
- F8 acil durdur
- Canlı tık sayacı

Not: QWERTY olmayan klavyelerde F1–F12 tuşları sistem/uygulama kısayollarıyla çakışabilir.
